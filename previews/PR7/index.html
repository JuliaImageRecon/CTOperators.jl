CTOperators.jl

Matched forward and back projectors for X-ray CT on CPUs and GPUs.

CTOperators.jl provides projection operators for tomographic reconstruction that run multi-threaded on the CPU and on GPUs (CUDA, AMD, Apple) from the same code. You create an operator once and apply it many times, which is what iterative solvers such as those of RegularizedLeastSquares.jl do. The forward projection op * x computes line integrals of an image x along the rays of a scan; the back projection adjoint(op) * y is its adjoint.

using CTOperators
image = ImageGeom(; dims=(128, 128, 128), deltas=(1.0, 1.0, 1.0))
geometry = helical_cone_beam(; angles=range(0, 4pi, 360), pitch=64, z0=-64, dso=256, dsd=512,
                             nu=256, nv=128, du=1.0, dv=1.0)
op = JosephProjector(image, geometry)        # Float32 on the CPU
y = op * rand(Float32, 128, 128, 128)        # projections, size (256, 128, 360)
Warning

CTOperators.jl is in an early stage of development and not registered yet; its interface may still change.

Features

  • Projectors for iterative reconstruction: a projector is created once and applied many times; the back projection is the exact adjoint of the forward projection.
  • Two ray-driven projectors: Siddon's method, which weights each voxel by the exact length of the ray inside it (in the incremental form of Jacobs et al.), and Joseph's method, which interpolates linearly between voxel centers; see Siddon's Method and Joseph's Method.
  • Generic geometries: arbitrary rays given by start and end points, and cone-beam (flat or curved detector) and parallel-beam scanners described view by view, with any source trajectory (circular, helical, ...), including objects that move during the scan. Geometries of Sinograms.jl work directly.
  • One code base for CPU and GPU, written with KernelAbstractions.jl: data as Array, CuArray (CUDA.jl), ROCArray (AMDGPU.jl) or MtlArray (Metal.jl).
  • Differentiable with respect to image and projection data (ChainRulesCore rules).

  • The API lists all types and functions.

Related packages

  • ImageGeoms.jl describes the voxel grid of the image; CTOperators.jl takes its ImageGeom and re-exports it.
  • ImagePhantoms.jl provides phantoms and their analytic projections; the examples and tests use them.
  • Sinograms.jl describes CT geometries and provides analytic reconstruction (FBP, FDK); the projectors accept its geometries directly.
  • RadonKA.jl computes Radon transforms and back projections, parallel-beam (also attenuated) and of arbitrary in-plane rays, slice by slice with KernelAbstractions.jl, also on GPUs.
  • SPECTrecon.jl provides forward and back projectors and ML-EM reconstruction for SPECT.
  • LinearOperatorCollection.jl collects linear operators (FFT, NFFT, wavelets, ...) for composing system matrices.
  • RegularizedLeastSquares.jl solves regularized least-squares problems (CGNR, FISTA, ADMM, Kaczmarz, ...); its solvers work with the projectors of CTOperators.jl.
