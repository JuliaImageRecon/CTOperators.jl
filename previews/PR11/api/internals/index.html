Internals

For developers of operators (see Implement a CT Operator): the functions each operator implements, the masks a projector stores, the kernel form of the image grid and the clipping of rays. None of these is exported.

Operator implementation

CTOperators.backward! — Function
backward!(x, op::AbstractCTOperator, y)

Back projection (the adjoint) of the projection data y into the image x, overwriting x. Implemented by every operator; users call mul!(x, adjoint(op), y) or adjoint(op) * y.

source
CTOperators.device_geometry — Method
device_geometry(geometry, T, storage)

geometry with its arrays in element type T on the device of storage, an array type such as Array or CuArray (or a concrete one such as CuArray{Float32}). Projector constructors call it with their keywords eltype and storage.

source
CTOperators.forward! — Function
forward!(y, op::AbstractCTOperator, x)

Forward projection of the image x (of size imagesize(op)) into y (of size datasize(op)), overwriting y. Implemented by every operator; users call mul!(y, op, x) or op * x.

source
CTOperators.similar_projector — Function
similar_projector(op::AbstractProjector, geometry; raymask=ray_mask(op))

A projector of the same kind and with the same image geometry and options as op, for geometry. The keyword raymask exists only for projectors that store a ray mask.

Masks of a projector

CTOperators.ProjectorMasks — Type
ProjectorMasks(image::ImageGeom, geometry, raymask)

The masks of a projector on the device of geometry: the image mask of image (nothing if all voxels are used) and the ray mask raymask (nothing, or a Bool array of the data size, true for the rays that are used). For implementations of projectors.

source
CTOperators.projector_masks — Function
projector_masks(op::AbstractCTOperator) -> ProjectorMasks

The masks of op. Projectors of this package store them. Default for an AbstractProjector: the mask of its ImageGeom, copied to the device at every call, and no ray mask. Default for any other AbstractCTOperator: no masks.

Image grid

CTOperators.VoxelGrid — Type
VoxelGrid{T}(ig::ImageGeom)

The voxel grid of an ImageGeom in the form the kernels use: three dimensions (a 2D ImageGeom becomes a volume with nz = 1 and voxel size 1 along z, centered at z = 0), element type T, no units. first is the world coordinate of the center of voxel (1, 1, 1); voxel (i, j, k) has its center at first + ((i, j, k) .- 1) .* deltas. Negative deltas (flipped axes, allowed by ImageGeoms) are kept.

lo and hi are the corners of the bounding box of the mask of the ImageGeom (the smallest box containing its voxels), in voxel coordinates (see to_index): [1/2, n + 1/2] per dimension without a mask. Projectors clip their rays to this box (Joseph widens it by half a voxel across the ray, for the interpolation), so that they do not traverse voxels that the mask sets to zero.

Units of the ImageGeom are stripped; they must be the units of the projection geometry.

source
CTOperators.bounds — Method
bounds(g::VoxelGrid) -> (lo, hi)

Corners of the box covered by the voxels (outer faces, not centers), lo .<= hi.

source
CTOperators.to_index — Method
to_index(g::VoxelGrid, p)

Continuous voxel coordinates of the world point p: voxel (i, j, k) covers [i − 1/2, i + 1/2) × …, its center has the integer coordinates (i, j, k). In these coordinates the voxels are unit cubes with positive orientation, whatever the sign of deltas.

source

Ray tracing

CTOperators.clip — Method
clip(p, d, dims, ::RaySegment | ::RayLine) -> (amin, amax)

Parameters of the part of the ray p + α d (voxel coordinates) inside the volume of size dims: the box [1/2, n + 1/2] per dimension, intersected with α ∈ [0, 1] for segments. The ray misses the volume if amin >= amax.

source
CTOperators.clip — Method
clip(p, d, lo, hi, ::RaySegment | ::RayLine) -> (amin, amax)

Parameters of the part of the ray p + α d inside the box [lo, hi], intersected with α ∈ [0, 1] for segments.
